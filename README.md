## 💡 选购指南

### 快速选择

| 预算/需求 | 推荐选择 |
| :--- | :--- |
| 💰 **极致低价** (月均＜5元) | 直连接入：良心云、亏本机场、一分机场、吹雪云 |
| 🔄 **性价比之选** (月均5-15元) | 中转：69云、神龙、雪山、两元店、喵喵 |
| 🎮 **游戏/流媒体** (月均15-30元) | 专线：肯の机、E-ix、WESTDATA · 中转：红杏 |
| 🚀 **大流量需求** | 北美机场、大机场、赔钱机场、KTM |

### 线路类型解释

| 类型 | 原理 | 优点 | 缺点 |
| :--- | :--- | :--- | :--- |
| **专线 (IEPL/IPLC)** | 不过墙，物理专线传输 | 零干扰、极低延迟、晚高峰稳定 | 价格较高 |
| **中转 (BGP/公网隧道)** | 国内优质服务器中转至海外 | 稳定性好、性价比高 | 受国内网络影响 |
| **直连** | 客户端直接连接海外节点 | 价格便宜 | 晚高峰可能丢包 |
